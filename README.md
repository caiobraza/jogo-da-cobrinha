# 🐍 Jogo da Cobrinha (Cyberpunk Edition)

Uma releitura moderna e estilizada do clássico **Jogo da Cobrinha (Snake)** desenvolvida em Python com a biblioteca `pygame`, trazendo paleta de cores **cyberpunk**, níveis de velocidade e código modularizado.

## ✨ Funcionalidades

* **Visual Cyberpunk:** Paleta de cores neon de alto contraste para a cobra, comida, grade e interface.
* **Níveis de Velocidade:** Opções de dificuldade com velocidades mais altas para testar os reflexos.
* **Sistema de Pontuação:** Contador de pontos em tempo real e tela de *Game Over* com opção rápida de reinício.
* **Código Organizado:** Estrutura modularizada para facilitar a leitura, manutenção e futuras melhorias.

---

## 🎮 Como Jogar

* **Setas Direcionais**: Controlam a direção da cobra.
* **Objetivo:** Coletar os pontos de energia na tela para crescer e aumentar a pontuação sem colidir com as bordas ou com o próprio corpo.

---

## 🛠️ Tecnologias Utilizadas

* **Python 3**
* **Pygame** (renderização gráfica, controle de FPS e captura de eventos do teclado)
